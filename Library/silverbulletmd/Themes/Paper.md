**Paper** is a pair of themes for long-form writing. [[Library/silverbulletmd/Themes/Paper/Light|Paper]] is brown ink on warm off-white paper with a muted red accent; [[Library/silverbulletmd/Themes/Paper/Night|Paper Night]] turns that into cream ink on dark brown. Tags become soft rounded pills, headings and rules are drawn in the same ink as the text.

Pick either in Configuration → Appearance → Theme, or with ${widgets.commandButton("Theme: Select")}. ${widgets.commandButton("Theme: Toggle Light/Dark")} switches between the two.

Both themes suggest **Lora**, a serif with brushed, calligraphic curves, as the editor font. Installing Paper installs the [[Library/silverbulletmd/Fonts/Lora|Lora]] font library for you, unless you already have it. Lora stays installed when you remove Paper; remove it separately if you no longer want it. The suggestion only applies while you haven't picked an editor font yourself.
